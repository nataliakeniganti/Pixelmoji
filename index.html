Setup

The generated style.css defines the font face Pixelmoji.
You can either copy the contents of style.css to your own CSS or link to it in your HTML like so: 

<link rel="stylesheet" href="style.css">
<link rel="preload" href="fonts/Pixelmoji.woff2" as="font" type="font/woff2" crossorigin="anonymous" />

The second line is for enabling early font downloads.

This code assumes style.css is located in the same directory as the HTML file linking to it. You may need to adjust the value of href and the URLs used within style.css depending on where you place the generated files in your setup.

Material Design Theme

This project includes Material Design 3 theme colors in multiple contrast levels. The themes are defined in separate CSS files that can be used individually or combined with your design system.

Available Themes:

  • light.css - Light theme (standard contrast)
  • light-mc.css - Light theme (medium contrast)
  • light-hc.css - Light theme (high contrast)
  • dark.css - Dark theme (standard contrast)
  • dark-mc.css - Dark theme (medium contrast)
  • dark-hc.css - Dark theme (high contrast)

Usage:

Each theme file defines CSS custom properties (variables) with Material Design color tokens. Include the desired theme in your HTML:

<link rel="stylesheet" href="light.css">
<link rel="stylesheet" href="dark.css">

Then apply the theme class to your root element:

<html class="light">
<!-- or -->
<html class="dark">

Accessing Colors in CSS:

Use the provided CSS custom properties to access Material Design colors throughout your application:

.my-element {
    background-color: var(--md-sys-color-primary);
    color: var(--md-sys-color-on-primary);
    border-color: var(--md-sys-color-outline);
}

Color Reference:

The theme files include variables for:

  • --md-sys-color-primary - Primary brand color
  • --md-sys-color-on-primary - Text color on primary
  • --md-sys-color-primary-container - Primary container color
  • --md-sys-color-on-primary-container - Text on primary container
  • --md-sys-color-secondary - Secondary color
  • --md-sys-color-tertiary - Tertiary color
  • --md-sys-color-error - Error/negative color
  • --md-sys-color-background - Background color
  • --md-sys-color-surface - Surface color
  • --md-sys-color-outline - Outline/border color
  • And many more semantic color tokens...

See the theme JSON export (material-theme.json) for the complete color palette and scheme definitions.

Inserting & Customizing

Use the CSS class emoji to apply the generated font to any text: 

<span class="emoji"></span>

You could change the size of the glyph using the font-size property in CSS: 

.my-size {
    font-size: 2em;
}

<span class="emoji my-size"></span>

You can specify which color palette to use like so:

<span class="emoji palette0"></span>

You could also customize a palette in CSS:

@font-palette-values --custom {
    font-family: "Pixelmoji";
    base-palette: 0;
    override-colors: 0 #f00, 1 blue, 2 rgba(0, 0, 0, 0.5);
}
.custom {
    font-palette: --custom;
}

<span class="emoji custom"></span>

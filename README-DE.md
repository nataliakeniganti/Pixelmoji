# Pixelmoji Schriftart 😀
Pixelmoji ist eine Schriftart mit pixeligen Emojis.

Änderungsprotokoll:
* Büroklammer und verknüpfte Büroklammern hinzugefügt
* Schüttelndes Gesicht hinzugefügt
* Spritzer hinzugefügt
* Gesicht mit Augenringen hinzugefügt
* Auto hinzugefügt
* Einige doppelte weiße Flaggen entfernt
* Khanda hinzugefügt
* Passkontrolle hinzugefügt
* Benutzerdefinierte Elemente hinzugefügt

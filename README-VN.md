# Pixelmoji Font 😀
Pixelmoji là một font có các biểu tượng cảm xúc (emoji) theo phong cách pixel.

Nhật ký thay đổi:
* Thêm Kẹp giấy và Kẹp giấy liên kết
* Thêm <img width="16" height="16" alt="shaking_face" src="svg/shaking_face.svg" /> Gương mặt run rẩy
* Thêm Dung dịch phun
* Thêm Khuôn mặt có vòng tối dưới mắt
* Thêm <img width="16" height="16" alt="automobile" src="svg/automobile.svg" /> Xe ô tô
* Xoá một số cờ trắng trùng lặp
* Thêm Khanda
* Thêm <img width="16" height="16" alt="passport_control" src="svg/passport_control.svg" /> Kiểm soát hộ chiếu
* Thêm <img width="16" height="16" alt="customs" src="svg/customs.svg" /> Hải quan
